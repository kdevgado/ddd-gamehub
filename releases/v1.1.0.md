# DDD Game Hub v1.1.0 — The Lounge Update

A new look for game night, with a calmer game hub and an easier experience on phones.

## A redesigned game hub

- Charcoal surfaces, warm accents, sculptural game artwork, and coordinated light and dark themes.
- Browse all seven games, filter by play style, or let **Surprise me** choose your next round.
- Launch a local game or open the selected online game directly from its card.
- How-to-play guides cover setup, rules, goals, and beginner tips for every game.

## Easier on mobile

- Readable game cards, visible navigation, larger tap targets, and more compact setup forms.
- Expand instructions when you need them, with less scrolling to start a game.
- Player entry shows how many names are still needed and keeps the keyboard ready for the next name.
- Joining a room moves smoothly from player name to room code.
- Local game screens, private roles, timers, and voting share the new styling.

## Game improvements

- Werewolf voting starts with **No elimination** selected, with clearer night-result and next-night actions.
- Guardian actions stay in the night phase, and Cupid-linked deaths are announced.
- Imposter and Werewolf discussion timers are off by default, with an option to enable them.
- UNO includes dedicated Wild card artwork.

## Performance and downloads

- Online room code loads when needed, reducing the initial hub download.
- Installed or cached local games remain available offline. Online UNO and Trivia Party require an internet connection.
- Windows and Android packages use version **1.1.0**; Android version code is **5**.
- Release downloads include the Windows installer, a signed Android APK, and its SHA-256 checksum.

Windows installers remain unsigned. Android updates use the existing release signing identity.
